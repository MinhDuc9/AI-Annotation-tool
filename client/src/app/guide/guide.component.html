AviScribe — Quick Guide

AviScribe is a collaborative image-annotation workspace for bounding boxes and keypoints (with skeletons). It supports real-time presence, role-based access, comments, undo/redo, COCO export, and smooth pan/zoom for large slides.

Core Concepts

  • Slides: Images inside a project. Use the left rail to switch slides.
  • Tools: Select, Bounding Box, Skeleton (keypoints + edges), and Pan/Hand.
  • Labels: Separate label sets for boxes and keypoints. Add, pick, and delete (when unused).
  • History: Undo/redo supports create, move, resize, color, and label changes.
  • Collaboration: Presence & locking prevent conflicts while others edit.
  • Comments: Real-time thread per slide, with optimistic posting and connectivity status.

Roles & Permissions

Project roles are enforced everywhere. Admin and Write can annotate. Read can pan/zoom and view annotations/comments but cannot use selection, box, or skeleton tools, and the Annotations tab is hidden for them.

Working with Tools

Pan & Zoom

  • Hold Space or use the Hand tool to drag the canvas.
  • Mouse wheel zooms around the cursor; zoom keeps stroke sizes readable.
  • Images auto-fit in the desk; thumbnails are generated lazily for the slide rail.

Select

  • Click a box edge to select; drag inside to move; drag a handle to resize.
  • Click a bone (edge) to select the whole skeleton; drag to move all points.
  • Click a point to select it; drag to move it (neighboring bones update).
  • Delete/Backspace removes the selected box, point, or skeleton.

Bounding Boxes

  • Draw with the Box tool; color and label live in the right sidebar.
  • Labels are name-based, de-duplicated case-insensitively. You can only delete labels that aren’t used.

Skeletons (Keypoints)

  • Click empty space to create a skeleton with one point (uses active keypoint label and color).
  • With a point selected, click empty space to add a point and auto-connect an edge.
  • Click an existing point:
    • Same skeleton: if not already connected, it links the points.
    • Different skeletons: merges into the selected skeleton (keeps its color), then links.
  • Keypoint labels are per-point; the skeleton’s color styles bones/handles.

Collaboration & Presence

  • Entering a slide joins its real-time room; leaving switches rooms automatically.
  • Locks are applied while someone is “touching” a box or keypoint to prevent conflicts.
  • Short delays on unlocks reduce flicker when people stop moving the mouse.
  • Participants & your avatar appear in the top bar; comments list shows authors by display name.

Comments

  • Each slide has a live comment thread.
  • Comments post optimistically and reconcile when the server confirms them.
  • Connectivity state is surfaced; failures are notified via snackbars.

Export

  • COCO (per slide): Export boxes and keypoints. Keypoints are independent from boxes; users decide if/how they relate. Image ids are non-hashed (stable by slide id), and category names come from your label sets.
  • COCO (all slides): From the project name menu, export an aggregate dataset across slides.
  • (Optional) Image ZIP export can be added later; it streams blobs with minimal memory overhead.

Keyboard Shortcuts

  • H Hand / Pan
  • V Select
  • B Bounding Box
  • K Skeleton
  • Space Hold to Pan
  • Delete / Backspace Delete selection
  • Ctrl/⌘ while adding points: Keep chaining
  • Top bar: Undo / Redo

Troubleshooting

  • If a tool seems disabled, check your role. Read-only users cannot annotate.
  • If images look soft: wait for the full image to load; thumbnails are lower-res.
  • If comments don’t appear, verify socket connection and reload the slide.
